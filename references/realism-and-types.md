# 真实感引擎 · 评论类型骨架

> **注**：运行所需的操作规范（七类骨架、配比、语料、反面清单、自检、表结构）已**内联进 `SKILL.md` 正文**，以 SKILL.md 为准。本文件是更详的背景/出处版，供想深读的人参考；无文件系统的部署环境（飞书 Agent/Coze）读不到本文件也不影响运行。

> 本文件是「水评生成」生成评论时的校准基准。核心信念（来自迷因手册）：
> **自然评论 = 一条具体表达，被视频某个点位触发后围绕内容继续讨论。**
> 真实感不来自单条写得多好，而来自**一堆评论凑在一起的参差不齐**——长短不一、标点不齐、口吻各异、类型混杂。整齐划一 = 假。

---

## 一、参差 = 三轴同时拉方差（长度 × 收尾 × 句式）

> **纠错**：早期版本照「蒸汽电波」定成「中评 58% 一档独大」，结果生成出来清一色 15–25 字完整句、都以句号收尾——那还是「统一」，只是换了种统一。**参差不齐不是某个平均值，是极端之间的落差**：2 个字的爆点和 30 字的长评并排、不加标点的和句号收尾的并排、单词碎片和完整句并排。**以 `SKILL.md` 第 3 步的「三轴配额 + 正反例」为准**，本节是背景。

**别让任何一档/一种占多数。** 每 20 条一批，三个轴都要铺开：

- **长度轴**（别都挤中间）：极短 2–6 字 5–6 条、短 7–14 字 4–5 条、中 15–25 字 6–7 条、长 26–40 字 3–4 条、超长 40+ 字 0 条。长度要从 2 字一路铺到 35+ 字。
- **收尾轴**（别写成每条都收得很完整）：不加收尾标点 8–10 条、句号 3–4、问号 2–3、感叹号 1–2、省略号 1、~/emoji 0–1、逗号断句不收尾 1。无标点必须占 35%–60%，连续 4 条同收尾＝失败。
- **句式轴**（别都完整句）：单词碎片（典/绝）、感叹短句（破防了）、run-on 一句到底、半句话（就……很离谱）、完整句——都要有。

一批里同时出现「离谱」这种两字弹和二十来字的具体描述、有句号的和没标点的、完整句和碎片——**这种落差本身就是真实感**。

### 标点风格（真实是「混着来」，向 master 文档对齐）
> **纠错**：早期版本照「蒸汽电波」那张表定成"全不加标点"，那是**单个账号的特殊风格，过拟合了**。master 文档的示例评论全是正常标点（「早起不难，难的是长期把自己的节奏稳定下来。」「这种方法要怎么调整比较合适？」）。真实评论区是**有的有标点、有的没有**，参差在于「混」，不在于「统一不加」。

- **中长评保留必要的内部标点，但不必补收尾句号**：`苹果都选百度搜，说明技术底子还在` 比每条都用句号封口更像手机随手评论。
- **短爆点/情绪弹多数不加标点**：离谱、绝了、麻了、瑞思拜。
- **点缀参差**：少量用 ！/？ 表强情绪、用 …… 或 ～ 拖尾、用 emoji、或一句到底不断句。整体看下来长短、标点、句式都不一样，才叫参差。
- **❌ 严禁用空格代替标点**：「沉默的用户撑起了百度 发声的用户重塑了口碑」这种拿空格分句 = **最明显的机器痕迹**，该逗号就逗号、该句号就句号。（英文/数字间的空格如「Scaling Law」「DeepSpeech 2」正常保留。）
- 偶尔全角引号强调某个词（"装作没事""欲言又止"），像人在复述画面。

## 二、评论类型骨架（七类打散混排，绝不整齐）

一批评论里尽量覆盖七类、比例不均、顺序打乱。每类锚定脚本里的**具体点位**（某个画面/金句/细节/观点），不许泛评全片。

1. **惊叹/爆点型**（多为极短）——被镜头/技术/反转击中：`离谱`｜`绝了`｜`恐怖如斯`｜`这也太真了`｜`第一次见AI能这样`
2. **共鸣/场景型**——描述脚本支持的日常场景；除非用户明确提供真实背景，否则不写具体身份经历：`家里长辈确实更习惯搜索框`｜`每天先折腾工具再开工太像很多人的状态`
3. **不同意见/反驳型**——形成讨论但不攻击人：`这个结论也不能一概而论`｜`老版本可能不是这样`
4. **追问/畅想型**——顺着内容往下想、要更多：`什么时候公测？我想去生一个`｜`以后是不是可以自己定制演员`｜`求个内测地址`｜`蹲一个教程`（问句自然带问号，也可不带，别统一）
5. **复述金句型**——用自己的话把视频核心判断重说一遍（迷因"活起来"的标志）：`情绪不是开关是一条慢慢走的弧线，这句太顶了`｜`原来高级的不是哭，是憋着不哭`
6. **玩梗/二创型**——接梗、造夸张画面：`横店连夜拆除`｜`离谱他妈给离谱开门`｜`导演们汗流浃背了`
7. **行业黑话/专业视角型**——用圈内词显得"懂行"：`这确定不是拿真人转描喂出来的`｜`连微表情的节点都不用调`｜`呼吸的生理细节都做出来了`

### 深一层的口吻纹理（可选叠加，让"人"更立体）
- **心理状态八分**：不知道→求解释；不信→"假的吧我不信"；焦虑→"是不是要被替代了"；愤怒→追问不公；想爽→喊反转打脸；想收藏→"先码后看"；无感→不产生评论（所以别写）。
- **多种表达角度**：同一批要有不同关注点和语气，但不得借此虚构多个具体身份或消费经历。

## 三、常用语料库（克制取用，别堆梗、别用过时梗）

> 网络梗有时效性。金标准表里含流行语的评论只占 **25%**，其余是**大白话**。堆梗反而假。以下是"当期还在用"的池子，每批只点缀性地用一部分。

- **情绪弹（极短）**：离谱 / 离大谱 / 绝了 / 绝子 / 麻了 / 破防了 / 红温了 / 瑞思拜 / 汗流浃背 / 恐怖如斯 / 逆天 / 跪了 / 震撼 / 哈人 / 捏把汗 / 瑟瑟发抖 / 上头
- **共鸣句式**：太真实了 / 终于有人说了 / 家里长辈常这样 / 很多人开工前就卡在这一步
- **认知反差**：没想到 / 第一次见 / 原来还能这样 / 这也太X了 / 卧槽真的假的
- **追问/蹲**：同问 / 蹲 / +1 / 求链接 / 什么时候 / 有没有懂的
- **保留意见**：不一定 / 也不能一概而论 / 老版本可能不是这样——让讨论有分歧，但不攻击人

## 四、反面清单（这些一出现就是"假"，自检必查）

- ❌ 每条都工整、都一个长度、都同一句式开头（"这个视频……""不得不说……"）
- ❌ 每条都无条件赞同、没有针对观点的保留意见
- ❌ 标点统一：全加句号、或全不加、或**全用空格分句**——统一（无论哪种）就是假；真实是有的有有的没有
- ❌ 机械替换关键词（把"眼神"换成"呼吸"再发一条）
- ❌ 泛评全片、不落到具体画面/金句（"太厉害了""做得真好"这种谁都能贴的万能水评）
- ❌ 堆过时热梗、用书面语、像新闻通稿
- ❌ 冒充真实消费者证言、编造具体购买/使用经历、虚假疗效收益

## 五、生成时的自检（配比 + 锚定 + 边界）

1. **三轴都拉开？**（**别再用「中评~58%」这种均值当目标——那正是翻车的老毛病，见第一节纠错**）①长度：从 2 字爆点一路铺到 35+ 字，没都挤在 15–25 字？有没有两字弹？有没有 26–40 字的具体长评？②收尾：无标点占 35%–60%，其余。/！/？/……/~ 混用？③句式：单词碎片、run-on、完整句都有，不是清一色完整句？
2. **标点自然混用？** 短爆点多不带收尾标点，中长评只保留必要的内部标点，没把每条完整句都封上句号？**没拿空格代替标点吧？**
3. **类型混？** 七类是否都有、顺序是否打乱、有没有对立面？
4. **锚定具体点位？** 每条都能指到脚本里的某个画面/金句/观点，而不是泛夸？
5. **表达角度不同？** 没有雷同句式和机械换词，也没有虚构多个具体身份？
6. **边界？** 不造谣、不攻击具体真人/群体、不虚假证言，讨论不越界？
